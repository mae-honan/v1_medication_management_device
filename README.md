Project Summary: 


Our project aims to make every-day tasks easier for the elderly. We designed, built, and programmed an automatic pill dispenser, where the user inputs their own custom medication schedule. When it is time to take medication, a passive buzzer goes off and the red LED light goes on to alert the user. The inner carousel holding the medication rotates so the medication is dispensed into the bowl. The user must press a button to confirm that they have taken it, then the buzzer and red LED turns off, and the OLED display shows how much time until the next dose.

Components Used: 


- Arduino Mega

- Full-size breadboard

- DS3231  RTC

- OLED SSD1306

- DRV8833

- 17HS19-2004S1 stepper motor

- Tactile push buttons

- Passive buzzer

- 2 LEDs 

- Resistor assortment
